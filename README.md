# 🐢 Turtle Race Game

A fun Python Turtle Graphics project where users bet on a turtle's color and watch six turtles race across the screen to determine the winner.

## Features

* Six colorful racing turtles
* User betting system
* Random turtle movement
* Winner announcement
* Built using Python's Turtle module

## Requirements

* Python 3.x
* Turtle (comes pre-installed with Python)

## How to Run

1. Save the Python file.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

4. Enter the color of the turtle you think will win.
5. Watch the race and see if your prediction is correct!

## Available Colors

* Red
* Orange
* Yellow
* Blue
* Green
* Purple

## Project Concepts

* Object-Oriented Programming (OOP)
* Turtle Graphics
* Lists
* Loops
* Conditional Statements
* Random Module
